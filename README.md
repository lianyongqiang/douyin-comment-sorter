# 抖音评论排序器

这是一个本地运行的Chrome浏览器插件，用来整理抖音网页版当前已经加载的主评论。

插件会在评论区内加入一条吸顶工具栏，并直接调整抖音原生评论卡片的展示顺序。滚动评论区时，工具栏会常驻顶部，不再使用侧边栏或悬浮窗。

工具栏采用与抖音评论区一致的深色设计：大圆角面板、粉色选中状态、线性功能图标、描边导出按钮和粉色刷新按钮。插件会实时监听评论区宽度：大于720px时显示完整按钮；不超过720px时立即切换为只显示图标的浓缩版，导出菜单仍显示完整文字。

## 功能

- 恢复插件首次读取时的页面顺序；
- 在原生评论区按点赞数从高到低排序；
- 在原生评论区按回复数从高到低排序；
- 评论区工具栏滚动吸顶；
- 滚动加载新评论后，一键刷新并重排；
- 导出当前主评论或当前排序前200条主评论；
- 读取失败时复制不含评论正文的诊断信息。

插件只移动页面中现有的完整评论节点，不复制或改写评论内容，不会自动点赞、回复或关注，也不会把评论上传到服务器。

## 使用限制

插件只整理页面当前已经加载的一级主评论。楼中楼回复不会计入已读取数量，也不会占用前200条的名额；“回复最多”仍使用每条主评论在页面上显示的回复总数。

如果需要更多评论，可以先继续滚动评论区，再点击“刷新并重排”。也可以使用“自动采集并导出前200条CSV”，让插件受控下滑并收集前200条。插件不能保证读取视频的全部评论。

## 下载与安装

先下载 [完整源码与安装包](./douyin-comment-sorter-1.0.0.zip?raw=true) 并解压。包内包含完整 TypeScript 源码、测试和已构建的 `dist`，普通使用不需要安装 Node.js。建议使用 Chrome 120 或更新版本。若使用 **Code → Download ZIP**，解压仓库后还需解压其中的安装包。

1. 在Chrome地址栏打开`chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的项目根目录，或其中的 `dist` 目录。

如果此前加载过旧版，请在扩展管理页面点击插件卡片上的刷新按钮。

## 使用方法

1. 打开抖音网页版视频，并展开评论区。
2. 等待评论显示后，使用评论区里的“点赞最多”或“回复最多”。
3. 排序结果会直接体现在抖音原生评论区。
4. 点击浏览器工具栏中的插件图标，可以重新显示并定位评论区工具栏。
5. 继续滚动加载评论后，点击工具栏右侧的“刷新并重排”。
6. 点击“导出CSV”打开菜单：
   - “导出当前CSV”导出当前已经读取的全部主评论；
   - “自动采集并导出前200条CSV”在不足200条主评论时自动缓慢下滑，达到200条后按照当前排序导出前200条主评论。

导出菜单点开后会保持展开，只有选择导出项或再次点击“导出CSV”才会收起。

点赞数相同时，回复较多的评论优先；回复数相同时，点赞较多的评论优先；仍然相同时保持页面原顺序。

抖音自身重新渲染评论区时，页面可能恢复平台原顺序。此时重新点击当前排序或“刷新并重排”即可。

CSV文件名格式为`douyin-comments-YYYY-MM-DD-HHmm.csv`，包含以下字段：

- 排名；
- 评论内容；
- 作者；
- 点赞数；
- 回复数；
- 发布时间，格式为“时间·归属地”。

自动采集设有滚动间隔、最大滚动次数和连续无新增停止条件。采集过程中可以点击“停止采集”，遇到登录或验证提示也会停止。插件只能收集抖音实际加载到页面中的评论，不保证每个视频都能达到200条。

插件会过滤「0分享回复」「0分享评论」「分享评论」等评论操作栏文字，避免把它们误当成评论正文。

## 常见问题

### 没看到评论区按钮

先打开视频评论区。若插件刚安装或更新过，在`chrome://extensions`刷新插件后，再刷新抖音页面。

### 读取数量少于页面显示的总评论数

这是正常限制。插件只读取当前加载到页面中的评论。继续滚动，再点击“刷新并重排”。

### 点赞数或回复数显示为0

页面可能没有展示该数字，也可能是抖音调整了页面结构。点击“复制诊断”，把诊断信息交给开发者更新识别规则。

### 点击插件图标没有反应

确认当前网页是`https://www.douyin.com/*`。新版会尝试自动连接当前页面，一般不再需要先刷新；如果Chrome仍拦截旧脚本，请在扩展管理页面刷新插件后重试。

## 本地开发

```bash
cd douyin-comment-sorter
npm ci
npm run dev
```

生成安装目录：

```bash
npm run build
```

构建结果位于`dist`。

## 权限

- `activeTab`：响应用户点击插件图标，并连接当前抖音页面；
- `scripting`：当前页面尚未连接时，补充加载评论整理程序；
- `https://www.douyin.com/*`：只在抖音网页版运行。

插件没有申请Cookie、浏览记录、书签、账号身份、网络拦截、下载管理或全部网站访问权限。

完整隐私说明见 [PRIVACY.md](./PRIVACY.md)。

界面图标使用Phosphor Icons，授权说明随插件一并提供。

## 安全边界

- 不读取Cookie或登录凭证；
- 不调用抖音未公开接口；
- 不拦截网络请求；
- 不绕过登录、验证码或平台限制；
- 不自动点赞、回复、关注或发布内容；
- 只移动完整评论节点，不改写节点内容；
- 不加载远程脚本。
